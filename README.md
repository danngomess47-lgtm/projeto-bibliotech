## 🎯 Sobre o Projeto
A **BiblioTech** tem como objeto social o desenvolvimento de soluções digitais voltadas à gestão de bibliotecas públicas, focando inicialmente na facilitação do cadastro de usuários, consulta de acervos, empréstimos e renovações de livros.
## 📊 Arquivos Disponíveis
- `BPMN-AS-IS.pdf`: Mapeamento do processo atual (manual, uso de carteirinha de papel e renovações via telefone).
- `BPMN-TO-BE.pdf`: Mapeamento do processo futuro otimizado via aplicativo móvel, com regras automatizadas e alertas preventivos.
